OBS Browser Source

  1. Copy the public scene URL.
  2. In OBS, add a Browser source.
  3. Paste the URL.
  4. Set width to 1920 and height to 1080.
  5. Leave the custom CSS box as it is. The scene is already transparent.
  6. Click OK. Move or resize overlays in the editor and OBS updates by itself.

Tip: add ?preview=true to the URL to check a scene in a normal browser tab.
